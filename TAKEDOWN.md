# Reporting an entry, or asking for one to come down

Stations are run by their operators, plugins and apps by their authors, and characters by whoever
wrote them. The catalogue lists them; it does not run or vouch for any of them. If an entry is yours
and you want it gone, or it is somebody else's and it should not be here, say so.

**You do not need a GitHub account.** Email [TAKEDOWN_EMAIL](mailto:TAKEDOWN_EMAIL) with:

- which entry: its name, or the address of its file here;
- what is wrong: yours and you want it removed, it infringes something of yours, it is harmful, it
  impersonates somebody, or it is not what it says it is;
- for a rights claim, what is yours and how to reach you.

With an account, you can instead open an issue, or use GitHub's **Report content** on anything here.

## What happens

An entry the report is plainly right about comes down first and is discussed after. A removal is an
ordinary commit, so it is public that it happened; what the report said is not.

A station that stops answering is not removed automatically. It is shown as not answering, and after
thirty days its operator is asked whether it is coming back.
